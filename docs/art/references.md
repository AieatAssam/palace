# Art references

Approved reference set for Palace. Each entry names one thing to take, not a style to copy.

| Reference | What to take |
| --- | --- |
| [The Room 4: Old Sins](https://store.steampowered.com/app/1361320/The_Room_4_Old_Sins/) | Single-key product lighting: one strong light, deep falloff, hard specular highlights on brass and lacquer. |
| [Strange Antiquities](https://store.steampowered.com/app/2885870/Strange_Antiquities/) | The desk is the interface: physical books, labels and objects instead of floating UI. |
| [Blue Prince](https://store.steampowered.com/app/1569580/Blue_Prince/) | The floor plan as menu: the hub reads as rooms of a palace you walk between. |
| [Botany Manor](https://store.steampowered.com/app/1425350/Botany_Manor/) | Progress kept as a handwritten ledger, in soft window light. |
| [Clair Obscur: Expedition 33 art blast](https://magazine.artstation.com/2025/05/sandfall-interactive-clair-obscur-expedition-33-art-blast/) | One period design language for every menu and card frame, so nothing reads as generic web UI. |

## Combined direction

Palace is a private study lit like a product shot: one warm key light from a window, deep shadow, and hard, small highlights on brass, lacquer and pearl. Everything you touch lives on the desk as an object: stage lists are bound books, progress is a ledger written by hand, choices are labels and cards you can pick up. The hub is a floor plan of the palace, each mode a room with its own furniture, reached through the plan rather than a grid of buttons. One period language (engraved serif, script accents, gilt rules, tooled leather) frames every card and menu, with no stock web chrome anywhere.
