# Palace — Art & UX Critique

**Date:** 2026-10-15 (Europe/London)  
**Build:** live at https://aieatassam.github.io/palace/  
**References:** see [references.md](references.md) for the approved reference set and combined direction.  
**Verdict:** the user is right. It reads as AI slop. The concept doc already named a premium direction; the prototype shipped the *words* of that direction (cream, serif, rosewood, brass) without the *discipline*. Premium is reduction and material honesty. This is decoration layered on a tutorial app.

## What “AI slop” means here

Not “it uses 3D.” Not “cream and serif.” Slop is the *pattern*:

1. A moodboard palette applied as CSS variables.
2. A display serif sprayed onto every surface (logo, prompt, note keys).
3. Soft glass panels, pill switches, radial glows — the 2023–2025 generative-UI default kit.
4. A 3D hero that looks like a textured box, not an object photographed in a room.
5. HUD and scene fighting for the same visual weight.

CULL died partly on “busy, confusing, AI-sloppy UX.” Palace is quieter, but it is the same family: *premium-coded packaging around an unfinished toy.*

## Slop tells (named, specific)

### 1. Banded procedural rosewood

`src/three/textures.ts` `makeRosewood` piles 1D noise into hard grain lines (`Math.pow(sin(...), 6)`). On the board it reads as **zebra stripes**, not rosewood pores. High contrast, repetitive along U, no large-scale colour drift, no oil finish. On SwiftShader it pixelates; on a real GPU it will still look synthetic because the *signal* is banded.

A luthier photo of Indian rosewood is quiet: dark chocolate, soft figure, pores as dots not dashes, finish catching a window once. Ours shouts “algorithm.”

### 2. Soft radial glow / halo sprites as the “question”

`makeGlow` / `makeHalo` are white radial gradients billboarded onto the target. In every Name-it shot: a fuzzy yellow-white ball floating on the nut or first fret. It does not light the wood, does not catch the fret wire, does not sit in the string’s specular. It is a **PowerPoint spotlight**.

Correct feedback keeps the same language (teal title + teal key). Miss uses burnt clay. Fine as colours; still no *physical* feedback on the instrument.

### 3. Glassmorphism HUD kit

From `styles.css`:

- Note pad: `backdrop-filter: blur(14px)`, inset highlight, soft drop shadow, 18px radius.
- Drill switch: pill + translucent fill + brass hairline — iOS segmented control cosplay.
- Top/bottom plaster fades (36px gradient) that **bleach the ends of the neck** so the instrument looks pasted into a UI sandwich.

This is the default “premium web app” kit. It is not an atelier. It is Linear / Notion / every AI landing page, tinted warm.

### 4. Typography without hierarchy

- **Cormorant Garamond** on wordmark, room label, prompt title, *and* every note key at 24px.
- **Inter** only on crumbs (`.prompt-sub`, progress).

Display serif on twelve equal buttons is costume. Note names should be a calm grotesque at one size. The serif earns its keep once: the question (“What note is this?”) or the room title — not both, and never the keypad.

Letterspacing on “Palace” is polite; “Fretboard” in italic Cormorant beside it is redundant chrome. Brand + room + mode switch + prompt = four competing headlines before you look at the neck.

### 5. Camera and stage that deny the object

- Flat plaster void. No bench, no table edge, no window falloff. The neck floats in cream.
- Landscape: three-quarter from the side, FOV 30 — readable, but **lit like a clay render**: soft ambient + contact shadow, frets without hard specular, strings without environment reflection.
- Portrait: neck vertical, heavy white fades top and bottom — the instrument is cropped by UI gradients, not framed by a camera.
- ContactShadows alone cannot sell “object on a surface” when the surface is the same colour as the sky.

Concept asked for “instrument on a table.” We shipped “diagram in a cream browser.”

### 6. Cluttered, inconsistent chrome

Always on screen during a trial:

| Element | Problem |
|---------|---------|
| Wordmark + room | Competes with prompt |
| Name it / Find all pill | Permanent mode chrome for a two-mode prototype |
| Settings sliders icon | Fine, but drawn as generic gear-lines |
| Prompt + subtitle | Good intent; serif size fights the neck |
| 12 equal glass keys | Piano truth (sharps shorter/darker) ignored |
| Stage title + hairline + streak | Third footer row of noise |

Find-all adds a second glass pill (“Tap each place… / Skip”). Onboarding is a frosted card *over* a fully active HUD — the scene is already shouting while you read “Welcome to Palace.”

Copy is mostly fine (“Name the glowing note” is honest but teaches the glow metaphor). Better: **“What note is this?”** — the glow should not be in the sentence.

### 7. Materials that do not agree

- Frets: brass/gold cylinders — real frets are nickel-silver, cooler, sharper specular.
- Wound strings: procedural helical normal + warm brass albedo — reads as gold wire, not phosphor bronze.
- Inlays: pearl maps exist (iridescence in full path) but in shots read as flat pale discs.
- Nut: simple grey block.
- No clearcoat story on the board finish; rosewood looks dry and noisy.

The stack *can* do physical materials. The lighting and texture choices refuse to.

## Top 6 problems (plain words)

1. **The wood looks fake** — striped procedural grain, not a quiet piece of rosewood.
2. **The question is a soft glow blob** — not light catching a fret and a string.
3. **The UI is stock glass and pills** — cream Linear, not a room with an instrument.
4. **Too much chrome at once** — logo, room, mode switch, big serif prompt, keypad, progress.
5. **Serif everywhere** — including on the note buttons; nothing feels designed, everything feels “elevated.”
6. **The neck floats in a void** — no bench, no window, no photographic framing; plaster fades eat the object.

## One art direction: **Bench photograph**

Not “Monument Valley + Arcade + Alto” as a cocktail. One sentence:

> **A single guitar neck on a luthier’s bench, shot like a museum product photograph — soft window light, honest materials, almost no UI — and the drill is naming what you see.**

References (borrow *behaviour*, not assets):

- **Luthier / PRS / Collings bench photography** — window key from upper left, dark board, cool fret wire, one specular run along a string.
- **Apple product pages (Watch, Pencil)** — object fills the frame; type is small, Inter-like, never competing.
- **Museum vitrine (Met instrument galleries)** — pin-spot on the exhibit, label discrete, glass not part of the brand.
- **Resident / Alto stillness** — empty negative space that is *composed*, not leftover.

Kill: glassmorphism, pill switches, radial glow sprites, Cormorant on keys, plaster gradient masks over the mesh, brass-gold frets, “Welcome to” cards that sit on a busy HUD.

### Palette (tight)

| Role | Hex | Use |
|------|-----|-----|
| Plaster | `#EDE6D9` | Stage / clear space (slightly less yellow than `#F4F0E8`) |
| Ink | `#1C1916` | Type, active controls |
| Stone | `#8A8478` | Meta, inactive |
| Rosewood | `#3F261C` → `#2A1812` | Board albedo range (darker, quieter than `#5C3A2E`) |
| Nickel | `#C8C2B4` | Frets, nut edge |
| Bronze string | `#A89868` | Wound strings only |
| Brass (UI only) | `#B08D57` | Hairline under active mode, progress fill — never frets |
| Correct | `#2F6F5E` | Key fill + short string shimmer |
| Miss | `#A65D3F` | Key border only — no screen flash |

No second cream. No oak in the fretboard room (save oak for a future hub shelf).

### Typography

- **UI:** Inter (or similar) only — 12 / 14 / 15. Mode labels uppercase tracked, not pills.
- **Display:** one serif (Instrument Serif or keep Cormorant) **only** for the in-trial question, one line, ≤34px desktop / ≤28px phone.
- Note keys: Inter Medium 14–15. Never serif on the pad.
- Wordmark: serif or ink wordmark once; room name as small caps Inter underneath — not italic Cormorant beside it.

### Material / lighting / camera spec

**Materials**

- Rosewood: replace procedural bands with a **baked or photo-based** albedo (or much softer noise: low-contrast pores, long gentle figure, clearcoatRoughness ~0.35, clearcoat ~0.4). Anisotropy along the neck axis.
- Frets: nickel, roughness ~0.25, metalness 1, slight rounded top — specular tick under the key light.
- Strings: cool grey for plains; bronze for wounds; environment reflection visible as a thin line, not a texture wallpaper.
- Inlays: small, recessed, pearl only as a soft sheen — no emissive.
- Target: **no glow sprite.** Prefer (a) a thin brass rect around the fret cell at 1–2px screen space, plus (b) a short emissive boost on that string segment / fret wire. The eye finds a highlight, not a fog.

**Lighting**

- One large soft key (window) from upper-left, intensity modest.
- Cool weak fill opposite; almost no rim.
- Studio HDR environment (neutral, low contrast) for metal reflections only.
- Contact shadow under the neck onto a **slightly darker bench plane** (oak or linen strip), not onto infinite plaster.
- Bloom: off during trials, or threshold so only the specular tick blooms — never the whole target.

**Camera**

- Landscape: three-quarter, nut left, slight elevation (~18–22°), FOV 28–32, neck lower-third so type can live above without covering wood.
- Portrait: nut top, neck fills width with **margin**, no white gradient masks — UI sits in clear plaster bands that do not composite over the mesh.
- Dolly only when the unlocked region changes; no idle camera swim.

### Minimal screen layout

```
[ Palace          · · · ]          (wordmark + settings only)
        What note is this?
           Low E · 1st fret

              [ neck ]

   NAME   find                      (text modes, not a pill)

   C  C♯  D  D♯  E  F  F♯  G  G♯  A  A♯  B
   (naturals tall/cream; accidentals short/rosewood)

   LOW E & A · 0–5  ————  0
```

Rules:

- One question. One object. One answer row.
- Mode switch is two words, not a control that looks like iOS.
- Onboarding: full-screen plaster, three short lines, one Continue — **HUD hidden** until skip/done.
- Find-all: prompt only; no second glass instruction bar — put “Skip” as text in the meta row.

## Suggested fix order (for a later PR — not done here)

1. **Kill the glow sprites**; brass cell + string specular for the target.
2. **Strip HUD:** hide brand during trial or shrink to ink word; text modes; Inter on keys; drop backdrop-filter pads.
3. **Replace rosewood map** (photo/baked or re-authored low-contrast grain) + nickel frets + cooler strings.
4. **Add a bench plane + window key**; remove plaster gradient masks over the canvas.
5. **Onboarding** as a clean interstitial with HUD off.
6. Re-capture on a **real GPU** (user’s phone + desktop) before calling the pass done.

No game code was changed in this critique. No push.
